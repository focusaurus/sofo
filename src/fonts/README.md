# Fonts

Vendored so exported PDFs embed the faces and render identically on any tablet,
with no network access needed at print time.

| File | Family | Source |
| --- | --- | --- |
| `patrick-hand-400.ttf` | Patrick Hand, regular | <https://fonts.google.com/specimen/Patrick+Hand> |
| `caveat-500.ttf` | Caveat, medium | <https://fonts.google.com/specimen/Caveat> |
| `caveat-600.ttf` | Caveat, semibold | <https://fonts.google.com/specimen/Caveat> |

All three are licensed under the [SIL Open Font License 1.1](https://openfontlicense.org/),
which permits redistribution and embedding, including in PDFs.

Patrick Hand is the default lyric face (`--font-lyric` in `sheet.css`). Caveat is
vendored as the looser, more script-like alternative — whimsier, but harder to
read at arm's length on a music stand.
